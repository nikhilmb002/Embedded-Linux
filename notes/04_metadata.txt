📑 What is Metadata in Yocto?

🔹 General Meaning (Non-Yocto)
	Metadata = “data about data” → information that describes or gives context to other data.

🔹 In the Yocto Project

	In Yocto, metadata is the set of instructions and data that tell the build system (BitBake) what to build, how to build it, and where to get it from.

	It defines things like:

		✅ Which software packages (and versions) should be included.
		✅ Where the source code comes from (Git, tarball, etc.).
		✅ What patches or customizations should be applied.
		✅ How the software should be compiled and configured for the target hardware.

		👉 In short: Metadata = the recipe book Yocto uses to cook your custom Linux distribution.

		📂 Types of Metadata Files
		Yocto metadata is made up of:

			Configuration files (.conf) → Set global or local build settings (e.g., target machine, distro features).
			Recipes (.bb and .bbappend) → Instructions for building specific packages (what source, how to compile, how to install).
			Classes (.bbclass) → Common functions or templates that can be shared across multiple recipes.
			Include files (.inc) → Fragments of metadata that can be reused in recipes for cleaner organization.
	
		✅ So, Metadata in Yocto = the blueprint + instructions that turn your input specifications into a working embedded Linux system.
