🌐 What is Poky?

	Poky is the reference distribution of the Yocto Project.
	The word reference here means example.

	It shows developers how to build a Linux system using Yocto tools.

	👉 Using Poky, developers can build complete images (kernel, system, and applications) for their target hardware.

🛠️ What Does Poky Contain?

	Poky is a git repository that combines several key components:

	BitBake → The build tool (like make but for Yocto).
	OpenEmbedded Core (OE-Core) → The core metadata (recipes, classes, configurations).
	meta-yocto-bsp → Example BSP (Board Support Package) layers for reference boards.
	Documentation → Guides and references for developers.

	📌 Note: Poky does not contain pre-built binaries.
	It is a working example of how to build a custom Linux distribution from source.

🔀 Difference Between Yocto and Poky

	Yocto Project												Poky
An umbrella project that provides tools, infrastructure, and metadata for building custom Linux systems.	A reference distribution (example implementation) created using Yocto tools.
Provides standards, guidelines, and collaboration space for embedded Linux development.				Provides a working example combining BitBake, OE-Core, meta-yocto-bsp & docs.
Think of it as the framework.											Think of it as the sample Linux distribution built with that framework.

👉 In simple words:

Yocto = The toolbox.
Poky = A sample project built using that toolbox.
